# [프로젝트 기획서] 반려견 맞춤형 안심 노면 산책 에이전트 및 기록·공유 플랫폼 (PawTrail)

## 1. 프로젝트 개요
* **프로젝트명**: PawTrail (포트레일, 가칭)
* **부제**: AI Native 반려견 맞춤형 안심 노면(Surface-aware) 산책 플래너 및 기록·공유 플랫폼
* **기획 배경 및 방향성**:
  - 복잡한 3D 건물 그림자 연산의 병목을 배제하고, 반려견의 발바닥 패드 화상, 딱딱한 지면의 충격으로 인한 관절 부담, 노령견 보행 피로의 실질적 핵심 원인인 **"지면 상태(노면 재질, 지면열, 현장 위험물)"**에 집중.
  - **사용자가 선호하는 노면 재질(흙길, 잔디길, 우레탄/탄성포장, 보도블록 등)을 직접 선택**할 수 있도록 지원하며, 선택된 노면에 높은 가중치(우선순위)를 부여하여 개인화된 최적 산책로를 생성.
  - **시선과 두 손의 자유 (Eyes-Free & Hands-Free)**: 하네스 줄을 잡고 스마트폰을 위험하게 들여다보는 대신, 스마트폰은 주머니에 넣고 귀로 듣는 **핸즈프리 음성 길 안내**를 통해 안전하고 온전한 반려견 중심 산책을 구현.
  - **AI Agent**, **Vision 멀티모달(안내판/노면 분석)**, **Long-term Memory(반려견 정보·노면 선호·산책 이력)**, **노코드 자동화(n8n)**, **React Native (Expo + EAS Update OTA)**를 결합하여 산책 계획부터 안전한 음성 가이드, 커뮤니티 공유까지의 전 주기를 완성.
* **핵심 타깃**:
  - 딱딱한 아스팔트 대신 푹신한 흙·잔디·탄성포장길 위주로 반려견에게 편안한 발걸음을 선물하고 싶은 견주
  - 여름철/낮 시간대 뜨거운 아스팔트 지면열 화상을 피하고 싶은 견주
  - 자차를 이용해 주차하기 편하고 원하는 노면이 풍부한 산책 코스를 찾는 원정 산책족
* **실사용자 테스트 목표**: 반려견 견주 최소 5인 이상 대상 필드 테스트 및 피드백 반영

## 2. 문제 정의 및 AI 기반 해결 방식

| 문제점 (Pain Points) | AI를 활용한 해결 방식 | 적용 기술 (필수 요건 충족) |
|---|---|---|
| **도심지 산책로의 노면 불확실성**<br>(국내 OSM 노면 속성 80% 결측) | 원시 위성 CV 대신 **환경부 토지피복지도(Land Cover Map) 세분류를 OSM과 공간 결합(Spatial Join)**하고, 검증된 시드 데이터를 융합해 0.1초 만에 흙/잔디/포장 비율을 판정하여 개인화 순환 코스 생성 | **Land Cover Spatial Join & Preference Routing Model** |
| **산책 중 폰 화면 주시의 위험성**<br>(리드줄 파지 중 화면 응시 시 낙상/돌발 사고) | 화면을 보며 걷는 위험을 원천 차단하기 위해, **주머니 속에서도 OSRM 스텝과 노면 속성을 결합해 회전 및 노면 변화를 알려주는 백그라운드 핸즈프리 음성 길 안내** 제공 | **React Native Expo (Background GPS & Speech TTS)** |
| **현장 노면 정보 및 진입로 규제 파악 한계**<br>(출입금지 구역, 비포장길 위치) | 산책 중 위험한 실시간 촬영 대신, **공원 입구 종합안내판 사진을 비전 모델이 판독(`ParkBoardInspector`)**하여 흙길/잔디마당 및 반려견 출입 금지 구역을 사전에 파악하고 경로에 반영 | **멀티모달 AI (Vision - 안내판 판독)** |
| **지도 데이터의 지속적 보정 부재**<br>(현장 공사, 노면 변경 미반영) | 산책 완주 후 견주가 남긴 노면 사진 후기를 **비전 모델이 자동 검증(`CommunityMapEnricher`)**하여 결측된 지도 링크의 노면 속성을 영구 갱신하는 참여형 선순환 구축 | **멀티모달 AI (Vision - 제보 검증)** |
| **반려견별 신체 조건 및 노면 선호 미반영**<br>(견종, 체중, 관절 안심 케어 선호, 선호 노면) | 견종 특성, 사용자가 설정한 관절 안심 케어 모드, 그리고 **사용자가 설정한 선호 노면 이력**을 기억하여 개인화된 코스 거리와 타깃 노면 비중을 최적화 (※ 의료 진단이 아닌 편안한 산책 참고 정보 제공) | **Long-term Context Memory** |
| **자연어 기반 복합 코스 생성의 번거로움** | "3살 말티즈, 관절 안심 케어 모드로 주차 편하고 **흙길/잔디 위주** 20분 코스 짜줘" 요청을 분석하여 DB 조회, 노면 가중치 매핑, 라우팅을 자율 순차 제어 | **AI Agent (ReAct Framework)** |
| **위험 지면열 시간대 파악 불가** | 기상청 기온/일사량 API와 경험적 지면열 수지식을 결합해 35℃ 이하 안전 시간대(골든타임)를 계산하여 추정 위험 정보 알림 발송 | **자동화 워크플로우 (n8n)** |

### 3.2 4대 필수 기술 요소 상세 명세
1. **AI Agent (Walk Planner Agent)**:
   - 자연어 질의 및 UI 입력을 파싱하여 `DogProfile`, `TargetDuration`, `PreferredSurfaces` 파라미터 추출.
   - Pydantic V2 기반 엄격한 스키마 검증을 거쳐 `get_dog_context`, `generate_loop_route`, `inspect_park_board`, `search_parking` 도구를 오케스트레이션.
2. **멀티모달 AI (Surface & Park Vision Inspector)**:
   - Gemini 1.5 Flash 기반으로 2가지 핵심 비전 기능 수행:
     1. **공원 종합안내판 판독 (`ParkBoardInspector`)**: 공원 입구 안내판 사진에서 흙길/잔디마당 산책로 범례와 반려견 출입 금지 구역을 파싱하여 구조화된 JSON(`ParkBoardInspectionResult`) 반환.
     2. **커뮤니티 제보 검증 (`CommunityMapEnricher`)**: 완주 후 견주가 업로드한 현장 노면 사진의 재질(`dirt`, `grass`, `paved` 등) 및 발바닥 위험요소를 검증하여 지도 링크 속성(`SurfaceEnrichmentResult`) 갱신.
3. **Long-term Memory (Canine Context Memory)**:
   - Supabase(PostgreSQL)에 견종, 체중, 관절 안심 케어 선호도(일반/폭신한 길 위주), **사용자 기본 선호 노면**, 이전 산책 피드백 및 나만의 코스 즐겨찾기 저장.
   - 에이전트 프롬프트에 최근 5회 산책 요약 및 맞춤형 가중치 주입.
4. **자동화 워크플로우 (n8n Webhook Pipeline)**:
   - 매일 오전 기상청 단기예보를 수집하고 경험적 지면열 수지식을 실행:  
     $$\text{Estimated Surface Temp} = \text{Air Temp} + (\text{Insolation Weight} \times 15)$$
   - 아스팔트 온도가 35℃ 이하로 내려가는 안전 시간대(골든타임)를 산출해 푸시/웹훅 알림 발송.

## 4. 사용자 선호 노면 선택 및 Waypoint 최적화·Routing API 연동 순환 라우팅

### 4.1 선호 노면 재질 선택 인터페이스
* 사용자는 앱 UI(필터 칩/라디오 버튼) 또는 대화형 Agent를 통해 원하는 1개 이상의 선호 노면을 선택:
  1. **흙길 (Dirt/Ground)**: 흙길, 숲길, 비포장 산책로 (환경부 토지피복: 나지)
  2. **잔디길 (Grass)**: 공원 잔디밭, 잔디 블록 (환경부 토지피복: 초지)
  3. **우레탄/탄성포장 (Rubber/Cushion)**: 조깅 트랙, 보행자 전용 탄성포장로
  4. **보도블록 (Paved)**: 일반 포장 보행로 (기본 평지)

### 4.2 가중치 비용 함수 (Cost Function) 공식
보행 네트워크 그래프 $G=(V, E)$에서 링크 $e$의 통행 비용은 다음과 같이 산출:

$$\text{Cost}(e) = \text{Length}(e) \times W_{\text{base}}(\text{surface}(e)) \times W_{\text{pref}}(\text{surface}(e), \text{SelectedPref})$$

* **사용자 선호도 보정 계수 ($W_{\text{pref}}$)**:
  - **선택된 선호 노면 링크**: **$0.4 \sim 0.5$** (비용을 50~60% 할인하여 **최우선 탐색**)
  - **선택되지 않은 중립 노면**: **$1.0$** (표준 비용)
  - **비선호/위험 노면 (아스팔트)**: **$2.5$** (낮 시간/지면열 시 우회 유도)
  - **기피 노면 (자갈/파쇄석)**: **$3.5$** (발바닥 끼임 우려로 강한 페널티)

### 4.3 다층 공간 데이터 융합 및 노면 출처(`surface_source`) 투명성 체계
국내 도심지 OSM의 높은 노면 결측률(80% 이상)을 극복하기 위해, **환경부 토지피복지도(Land Cover Map) 세분류 및 공공 폴리곤과의 공간 결합(Spatial Join)**을 우선 적용하고 데이터 출처를 투명하게 제공:

1. **`seed_verified` (신뢰도 0.95)**: 5인 CBT 시범구역(공원 반경 1.5km) 정사영상(항공/위성사진) 및 로드뷰 육안 교차 검증 시드 데이터셋.
2. **`land_cover_map` (신뢰도 0.85~0.90)**: 환경부 토지피복지도 세분류 공간 결합 판정 (초지=잔디, 나지=흙길, 인공포장=아스팔트/보도블록).
3. **`park_polygon` (신뢰도 0.75)**: 도시공원 경계 내부 링크 중 태그 결측 시 흙길(기본) 추정.
4. **`community_verified` (신뢰도 0.80~0.90)**: 완주 후 견주가 업로드한 현장 사진을 비전 AI가 검증하여 승인한 데이터.
5. **`estimated` (신뢰도 0.50)**: 일반 도로망 위계 기반 기본 Fallback (보행자전용=보도블록, 일반도로=아스팔트).

* **선호 노면 점유율 원칙**: 특정 도심지의 지리적 한계를 고려하여 **"선호 노면 50% 이상을 무조건 보장"하지 않으며**, 가능한 후보 중 비율을 최대화하고 미달 시 사유(예: "주변 잔디/흙길 부족으로 38%로 구성")를 사용자에게 정직하게 안내.

|---|---|---|---|
| **노면 맞춤 플래닝** | **선호 노면 & 산책 시간 맞춤 코스 생성** | 목표 시간(10~90분) 및 선호 노면(흙/잔디)을 반영해 토지피복 공간결합 기반 가용 노면 비중을 극대화한 순환 산책로 생성 | AI Agent + Routing API + Spatial Join Tool |

## 6. 비기능 요구사항 및 제약사항

* **성능 및 응답성 (NFR-01)**: AI Agent 복합 코스 생성 완료 시간은 5초 이내 완료 (노면 가중치 연산 최적화).
* **배포 및 무중단 업데이트 (NFR-02)**: React Native (Expo) 기반 **EAS Build로 테스터용 APK 1회 배포**를 수행하며, 이후 모든 로직/UI 수정은 **EAS Update (`expo-updates`) 무중단 OTA 배포**를 통해 재설치 없이 실시간 반영. 백엔드는 Render/Cloud Run 배포.
* **시선 해방 핸즈프리 안전성 (NFR-03)**: 스마트폰 화면을 계속 응시하며 걷는 위험한 보행을 방지하기 위해, **OSRM Steps와 노면 속성을 결합한 핸즈프리 음성 안내(갈림길 회전, 흙길 진입, 횡단보도 주의 알림)**를 백그라운드로 제공하여 견주가 두 손으로 리드줄 통제에 전념할 수 있도록 보장.
* **AI 윤리 및 의료 진단 배제 (NFR-04)**: AI 분석 및 추천은 안전하고 편안한 산책 계획을 위한 참고 정보이며 의료적 진단이 아님을 고지. 위치 정보 수집 시 사전 동의 절차 준수 및 커뮤니티 공유 시 좌표 블러링 적용.
* **버전 관리 및 협업 (NFR-05)**: GitHub 기반 feature 브랜치 분기 및 Merge Request(MR) 단위 코드 리뷰 운용.

## 7. 실사용자(최소 5인) 테스트 및 피드백 반영 계획

* **테스트 대상**: 실제 반려견 견주 5명 이상 (소형견 2, 대형견 2, 노령/집중 안심 케어견 1)
* **테스트 시나리오**:
  1. EAS Build로 배포된 APK 설치 후 반려견 프로필(견종, 체급, 관절 안심 케어 선호) 등록
  2. **사용자 선호 노면 선택 (예: "흙길+잔디길" 선택 후 20분 코스 생성 요청)**
  3. 스마트폰을 주머니에 넣고 **핸즈프리 음성 안내를 들으며 안전하게 산책 수행**
  4. 추천 경로에서 실제 선호 노면 비율(흙길/잔디길)이 적절히 반영되었는지 산책 수행
  5. 산책 중 노면 사진 1회 촬영·업로드하여 비전 판독 검증
  6. 산책 종료 후 기록 저장 및 피드백 설문(선호 노면 만족도, 음성 안내 편의성) 제출
* **피드백 반영 체계**:
  - 수집된 피드백을 바탕으로 노면 선호도 할인 계수($W_{\text{pref}}$) 및 프롬프트 즉각 수정
  - 수정 사항은 `eas update` OTA로 즉시 배포하여 테스터가 재설치 없이 다음 산책 시 개선된 기능을 즉시 체감할 수 있도록 구현
