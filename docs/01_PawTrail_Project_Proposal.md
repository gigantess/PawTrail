# [프로젝트 기획서] 반려견 맞춤형 안심 노면 산책 에이전트 및 기록·공유 플랫폼 (PawTrail)

## 1. 프로젝트 개요
* **프로젝트명**: PawTrail (포트레일, 가칭)
* **부제**: AI Native 반려견 맞춤형 안심 노면(Surface-aware) 산책 플래너 및 기록·공유 플랫폼
* **기획 배경 및 방향성**:
  - 복잡한 3D 건물 그림자 연산의 병목을 배제하고, 반려견의 발바닥 패드 화상, 관절 질환(슬개골 탈구 등), 노령견 보행 장애의 실질적 핵심 원인인 **"지면 상태(노면 재질, 지면열, 현장 위험물)"**에 집중.
  - **사용자가 선호하는 노면 재질(흙길, 잔디길, 우레탄/탄성포장, 보도블록 등)을 직접 선택**할 수 있도록 지원하며, 선택된 노면에 높은 가중치(우선순위)를 부여하여 개인화된 최적 산책로를 생성.
  - **AI Agent**, **Vision 멀티모달(노면 분석)**, **Long-term Memory(반려견 건강·노면 선호·산책 이력)**, **노코드 자동화(n8n)**를 결합하여 산책 경로 생성부터 산책 기록, 커뮤니티 공유까지의 전 주기를 완성.
* **핵심 타깃**:
  - 슬개골 탈구, 관절염 등으로 푹신한 흙·잔디·탄성포장길 산책이 필수적인 견주
  - 여름철/낮 시간대 뜨거운 아스팔트 지면열 화상을 피하고 싶은 견주
  - 자차를 이용해 주차하기 편하고 원하는 노면이 풍부한 산책 코스를 찾는 원정 산책족
* **실사용자 테스트 목표**: 반려견 견주 최소 5인 이상 대상 필드 테스트 및 피드백 반영

## 2. 문제 정의 및 AI 기반 해결 방식

| 문제점 (Pain Points) | AI를 활용한 해결 방식 | 적용 기술 (필수 요건 충족) |
|---|---|---|
| **도심지 산책로의 노면 불확실성**<br>(상용 지도는 아스팔트/흙길 구분 없음) | OSM 도로망의 노면(`surface`) 태그 정규화/추정 규칙을 적용하고, **Agent가 Waypoint를 자율 결정하여 Routing API를 호출**한 뒤 사용자 선호 노면 가중치 비용 평가를 거쳐 맞춤형 순환 코스 생성 | **Agent-Tool Routing & User-Preference Cost Model** |
| **실시간 현장 노면 위험**<br>(파쇄석, 공사 잔해, 깨진 유리, 물/진흙) | 견주가 현장 노면 사진을 찍어 올리면 Vision 모델이 시각적 위험 요소를 0~100점으로 즉각 판독하고 안전 경고 및 필요 시 우회 경로 재탐색 연계 | **멀티모달 AI (Vision)** |
| **반려견별 신체 조건 및 노면 선호 미반영**<br>(견종, 체중, 관절 주의 상태, 선호 노면) | 견종 특성, 사용자가 입력한 관절 상태, 그리고 **사용자가 설정한 선호 노면 이력**을 기억하여 개인화된 코스 거리와 타깃 노면 비중을 최적화 (※ 의료 진단이 아닌 참고 정보 제공) | **Long-term Context Memory** |
| **자연어 기반 복합 코스 생성의 번거로움** | "3살 말티즈, 슬개골 주의 필요한데 주차 편하고 **흙길/잔디 위주** 20분 코스 짜줘" 요청을 분석하여 DB 조회, 노면 가중치 매핑, 라우팅을 자율 순차 제어 | **AI Agent (ReAct Framework)** |
| **위험 지면열 시간대 파악 불가** | 기상청 기온/일사량 API와 경험적 지면열 수지식을 결합해 35℃ 이하 안전 시간대(골든타임)를 계산하여 추정 위험 정보 알림 발송 | **자동화 워크플로우 (n8n)** |

## 3. 핵심 AI 아키텍처 및 필수 기술 요소 명세

### 3.1 시스템 아키텍처 다이어그램
```
                 [ 사용자 (자연어 발화 / 선호 노면 재질 선택 / 현장 노면 사진) ]
                                                │
                                                ▼
                       ┌────────────────────────────────────────────────┐
                       │           Walk Planning AI Agent               │ ◄───► [ Long-term Memory ]
                       │          (LangGraph ReAct Pattern)             │       (반려견 프로필, 관절 병력,
                       └────────────────────────┬───────────────────────┘        기본 선호 노면, 산책 피로도)
                                                │ 도구 호출 (Tool Calling - Strict Pydantic)
           ┌────────────────────────────────────┼────────────────────────────────────┐
           ▼                                    ▼                                    ▼
 [ Tool 1: Surface Routing Engine ]    [ Tool 2: Vision Inspector ]         [ Tool 3: Public APIs ]
 - 사용자 선택 노면 고가중치 반영       - 현장 사진 노면 분류 (Gemini Flash) - 전국 공영주차장 실시간 정보
 - OSM 노면 결측 Fallback 룰 적용      - 위험 점수(0~100) 및 경고 생성      - 기상청 단기예보 / 지면열
 - 맞춤형 순환(Loop) 경로 연산          - 비전 위험도 라우팅 피드백           - P&R(Park & Walk) 코스 도출
           │                                    │                                    │
           └────────────────────────────────────┴────────────────────────────────────┘
                                                │
                                                ▼
                                [ 기록 & 커뮤니티 공유 모듈 ]
                                (산책 완주 경로, 노면 분석 리포트 피드 공유)
                                                │
                                                ▼
                                [ n8n 일일 알림 자동화 워크플로우 ]
                                (기상청 일사량 모니터링 → 안전 산책 타이밍 푸시)
```

### 3.2 4대 필수 기술 요소 상세 명세
1. **AI Agent (Walk Planner Agent)**:
   - 자연어 질의 및 UI 입력을 파싱하여 `DogProfile`, `TargetDuration`, `PreferredSurfaces` 파라미터 추출.
   - Pydantic V2 기반 엄격한 스키마 검증을 거쳐 `get_dog_context`, `generate_loop_route(preferred_surfaces)`, `analyze_surface_image`, `search_parking` 도구를 오케스트레이션.
2. **멀티모달 AI (Surface Safety Inspector)**:
   - Gemini 1.5 Flash 기반으로 현장 노면 이미지를 분석하여 노면 유형(`dirt`, `grass`, `paved`, `rubber`, `asphalt`, `gravel`) 식별.
   - 바닥의 균열, 가열 상태, 이물질(유리, 뾰족한 파쇄석)을 검출하고 구조화된 JSON(`safety_score`, `hazard_detected`, `ai_comment`) 반환.
3. **Long-term Memory (Canine Context Memory)**:
   - Supabase(PostgreSQL)에 견종, 체중, 관절 질환 단계, **사용자 기본 선호 노면(기본값 흙/잔디길 등)**, 이전 산책 피드백 저장.
   - 에이전트 프롬프트에 최근 5회 산책 요약 및 맞춤형 가중치(예: 사용자가 잔디길 선택 시 잔디 링크 선호도 극대화) 주입.
4. **자동화 워크플로우 (n8n Webhook Pipeline)**:
   - 매일 오전 기상 데이터를 수집하고 경험적 지면열 회귀식을 실행:  
     $$\text{Estimated Surface Temp} = \text{Air Temp} + (\text{Insolation Weight} \times 15)$$
   - 아스팔트 온도가 35℃ 이하로 내려가는 안전 시간대를 산출해 푸시/웹훅 알림 발송.

## 4. 사용자 선호 노면 선택 및 Waypoint 최적화·Routing API 연동 순환 라우팅

### 4.1 선호 노면 재질 선택 인터페이스
* 사용자는 앱 UI(필터 칩/라디오 버튼) 또는 대화형 Agent를 통해 원하는 1개 이상의 선호 노면을 선택:
  1. **흙길 (Dirt/Ground)**: 흙길, 숲길, 비포장 산책로
  2. **잔디길 (Grass)**: 공원 잔디밭, 잔디 블록
  3. **우레탄/탄성포장 (Rubber/Cushion)**: 조깅 트랙, 보행자 전용 탄성포장로
  4. **보도블록 (Paved)**: 일반 포장 보행로 (기본 평지)

### 4.2 가중치 비용 함수 (Cost Function) 공식
보행 네트워크 그래프 $G=(V, E)$에서 링크 $e$의 통행 비용은 다음과 같이 산출:

$$\text{Cost}(e) = \text{Length}(e) \times W_{\text{base}}(\text{surface}(e)) \times W_{\text{pref}}(\text{surface}(e), \text{SelectedPref})$$

* **사용자 선호도 보정 계수 ($W_{\text{pref}}$)**:
  - **선택된 선호 노면 링크**: **$0.4 \sim 0.5$** (비용을 50~60% 할인하여 **최우선 탐색**)
  - **선택되지 않은 중립 노면**: **$1.0$** (표준 비용)
  - **비선호/위험 노면 (아스팔트)**: **$2.5$** (낮 시간/지면열 시 우회 유도)
  - **기피 노면 (자갈/파쇄석)**: **$3.5$** (발바닥 끼임 우려로 강한 페널티)

### 4.3 OSM 노면 결측치 추정(Fallback) 및 투명성 원칙
* OSM 노면 태그 누락 시 다음 규칙으로 추정하되, **실측값/확정값처럼 표시하지 않고 추정 정보(`surface_source: estimated`, `surface_confidence`)로 다룸**:
  - `highway=footway | pedestrian` 중 태그 누락: `surface=paved` 추정 (보도블록, 가중치 1.0)
  - 도시공원 폴리곤 경계 내부 링크 중 태그 누락: `surface=dirt` 추정 (흙길, 기본 0.6 / 사용자 선호 시 0.45 적용)
  - `highway=residential | tertiary` (일반 도로): `surface=asphalt` 추정 (아스팔트, 가중치 2.5 페널티)
  - `surface=gravel | ground_rough` (자갈/파쇄석): 가중치 3.5 페널티
* **선호 노면 점유율 원칙**: 특정 지역(도심지 등)의 노면 분포 한계를 고려하여 **"선호 노면 50% 이상을 무조건 보장"하지 않으며**, 가능한 후보 중 선호 노면 비율을 최대화하고 목표 충족이 어려울 경우 사용자에게 사유(예: "주변 잔디/흙길 부족으로 38%로 구성")를 안내.

* **버전 관리 및 협업 (NFR-05)**: GitHub 기반 PR 단위 코드 리뷰 및 이슈 트래커 운용.

## 7. 실사용자(최소 5인) 테스트 및 피드백 반영 계획

* **테스트 대상**: 실제 반려견 견주 5명 이상 (소형견 2, 대형견 2, 노령/관절질환견 1)
* **테스트 시나리오**:
  1. 배포 웹 링크 접속 후 반려견 건강 프로필 등록
  2. **사용자 선호 노면 선택 (예: "흙길+잔디길" 선택 후 20분 코스 생성 요청)**
  3. 추천 경로에서 실제 선호 노면 비율(흙길/잔디길)이 적절히 반영되었는지 산책 수행
  4. 산책 중 노면 사진 1회 촬영·업로드하여 비전 판독 검증
  5. 산책 종료 후 기록 저장 및 피드백 설문(선호 노면 만족도, 앱 편의성) 제출
* **피드백 반영 체계**:
  - 수집된 피드백을 바탕으로 노면 선호도 할인 계수($W_{\text{pref}}$) 및 프롬프트 즉각 수정
  - 수정 내역을 GitHub 커밋 및 릴리즈 노트에 명시하여 미션 요구사항 100% 충족

## 8. 향후 비즈니스 확장 모델

* **반려견 동반 상권 연계**: 안심 산책로 주변 펫 프렌들리 카페, 동물병원, 펫숍 할인 쿠폰 매핑.
* **지자체 반려견 인프라 개선 데이터 제공**: 견주들의 노면 제보 및 통행 데이터를 분석해 '흙길 산책로 보수', '배변 봉투함 설치' 최적 입지 리포트 공급.
