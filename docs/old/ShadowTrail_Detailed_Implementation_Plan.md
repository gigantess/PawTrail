# [상세 구현 계획서] ShadowTrail 단계별 기술 구현 로드맵

## 1. 기술 스택 (Tech Stack)

* **프론트엔드 (Mobile App)**:
  * Framework: React Native (Expo)
  * Map Rendering: Mapbox GL / MapLibre Native
  * 상태 관리: Zustand / TanStack Query
* **백엔드 (API & 라우팅)**:
  * Framework: Node.js (Express or NestJS) / Python (FastAPI - GIS 연산 모듈)
  * Spatial Database: PostgreSQL + PostGIS
  * Routing Engine: Valhalla or OSRM (Open Source Routing Machine)
  * Batch Processor: Celery / Python (그림자 타일 사전 연산)
* **인프라 & 외부 연계**:
  * Cloud: AWS (ECS, RDS, S3, CloudFront)
  * 데이터: 공공데이터포털(주차장, 3D건물), OpenStreetMap(OSM)

---

## 2. 세부 단계별 실행 계획 (16주 로드맵)

```
[Phase 1: 1~4주]  데이터 인프라 및 GIS 파이프라인 PoC
       │
[Phase 2: 5~8주]  가중치 라우팅 코어 엔진 & 루프 코스 알고리즘
       │
[Phase 3: 9~12주] 모바일 클라이언트 개발 및 시각화
       │
[Phase 4: 13~16주] 현장 실측, 크라우드소싱 구축 및 CBT
```

---

### Phase 1: 데이터 파이프라인 및 GIS 엔진 PoC (1~4주차)

#### 1주차: 테스트베드 선정 및 데이터 파싱
* **목표**: 1개 특정 자치구(예: 대전 유성구 전민/신성동 또는 서울 마포구 상암동 일대) 대상 공간정보 구축.
* **세부 작업**:
  * OSM 도보 네트워크 데이터(.osm.pbf) 다운로드 및 `osm2pgsql`을 통한 PostGIS 적재.
  * 국가공간정보포털 건축물 연령/형상 3D 데이터(SHP) 다운로드 후 높이 필드 정제.
  * 공공데이터포털 전국 공영주차장 데이터셋 수집 및 위경도 정밀 좌표 지오코딩.

#### 2주차: 그림자 지오메트리 연산 엔진 개발
* **목표**: 태양 고도/방위각 기반 건물 그림자 폴리곤 투영 스크립트 완성.
* **세부 작업**:
  * Python `shapely` 및 `pyproj` 라이브러리 기반 2.5D 그림자 투시 연산 모듈 작성.
  * 계산식: 건물 높이 $H$, 태양 고도 $\alpha$, 태양 방위각 $\theta$ 일 때 지면 그림자 길이 $L = \frac{H}{\tan(\alpha)}$, 투영 벡터 $\vec{v} = (L \sin(\theta + 180^\circ), L \cos(\theta + 180^\circ))$.
  * 건물 바닥 다각형을 $\vec{v}$ 방향으로 Extrusion한 Convex Hull 생성.

#### 3주차: 노면(Surface) 데이터 정제 및 결측 보정
* **목표**: 보행 링크별 노면 메타데이터 완성도 제고.
* **세부 작업**:
  * OSM의 `surface` 태그(`asphalt`, `unpaved`, `ground`, `grass`, `paving_stones`) 정규화.
  * 결측 링크 처리: 도시공원 폴리곤 내부에 포함된 링크는 `surface=unpaved_park`로 일괄 매핑하는 PostGIS 공간 쿼리 실행.

#### 4주차: 데이터 통합 및 1차 PoC 검증
* **목표**: 특정 시간대(예: 여름철 14:00) 정적 지도상에 그늘/노면 래스터 레이어 합성.
* **산출물**:
  * PostGIS 기반 통합 도로망 DB
  * QGIS를 활용한 그림자 및 노면 오버레이 검증 리포트

### Phase 2: 라우팅 코어 엔진 및 루프 알고리즘 구현 (5~8주차)

#### 5주차: 라우팅 엔진(Valhalla) 환경 구축
* **목표**: 커스텀 가중치(Costing Model)를 주입할 수 있는 라우팅 서버 배포.
* **세부 작업**:
  * Valhalla Docker 컨테이너 셋업 및 보행 프로파일(`pedestrian`) 구성.
  * 링크별 속성 필드에 `surface_type` 및 시간대별 `shade_ratio` 주입 인터페이스 설계.

#### 6주차: 시간대별 그림자 사전 연산 타일(Pre-computed Tiles) 구축
* **목표**: 실시간 3D 연산 부하를 해소하기 위한 배치 캐싱 시스템 구축.
* **세부 작업**:
  * 오전 9시부터 오후 7시까지 1시간 간격(총 11개 슬롯) 그림자 마스크 생성 배치 스크립트 작성.
  * 도로 링크(LineString)와 그림자 다각형 간의 교차 길이 비율($\frac{\text{Length}_{\text{shadow}}}{\text{Length}_{\text{total}}}$)을 링크 메타데이터로 사전 계산하여 캐싱.

#### 7주차: 순환형(Loop) 산책로 생성 알고리즘 구현
* **목표**: 주차장 출발 $\to$ 목표 거리 도달 $\to$ 주차장 복귀 알고리즘 개발.
* **세부 작업**:
  * 입력: 주차장 노드 ID, 목표 거리 $D$ (km).
  * 알고리즘 로직:
    1. 주차장 중심 원주 상에서 일정 각도차를 갖는 3개 임의 웨이포인트 클러스터링.
    2. 생성된 웨이포인트를 연결하는 가중치 경로 탐색.
    3. 최저 비용(그늘+노면 점수 우수) 코스 3종 도출 (예: '그늘 최우선 코스', '흙길 최우선 코스', '밸런스 코스').

#### 8주차: 엔진 성능 튜닝 및 부하 테스트
* **목표**: API 응답 시간 1.5초 이내 달성.
* **세부 작업**:
  * 인덱싱 최적화 및 타일 기반 라우팅 쿼리 속도 프로파일링.
  * 단위 테스트 케이스 작성 (비정상 고립 루프 회피, 유턴 방지 로직).

---

### Phase 3: 모바일 클라이언트 개발 및 시각화 (9~12주차)

#### 9주차: 클라이언트 지도 인터페이스 및 스타일링
* **목표**: Mapbox 기반 산책 특화 맵 뷰 구성.
* **세부 작업**:
  * React Native Mapbox 모듈 연동.
  * 노면 재질에 따른 경로 선(Polyline) 색상 코딩: 잔디(초록 #4CAF50), 흙(갈색 #8D6E63), 포장/아스팔트(회색 #9E9E9E).
  * 실시간 그림자 영역 반투명 다각형 오버레이 렌더링.

#### 10주차: 주차장 탐색 및 산책 코스 선택 UI
* **목표**: 직관적인 산책 탐색 플로우 완성.
* **세부 작업**:
  * "주차장 탐색" 탭: 주차 가능 면수, 거리, 요금 표기 바텀시트.
  * "코스 요약 카드": 총 거리, 예상 소요 시간, 그늘 지수(%), 관절 보호 지수(%) 인포그래픽.

#### 11주차: 산책 모드 및 실시간 네비게이션
* **목표**: 실제 산책 진행 화면 구현.
* **세부 작업**:
  * GPS 기반 위치 트래킹 및 경로 이탈 재탐색(Rerouting) 로직.
  * '뜨거운 노면 진입 50m 전' 진동/음성 경고 알림 구현.

#### 12주차: 백엔드 API 연동 및 통합 테스트
* **목표**: Client-Server 통신 및 인증, 사용자 설정 연동.
* **세부 작업**:
  * 반려견 프로필 등록 (견종, 체중, 관절 질환 여부 $\to$ 맞춤형 가중치 자동 보정).
  * 클라이언트-서버 간 E2E 통신 점검.

---

### Phase 4: 필드 검증, 크라우드소싱 및 릴리즈 (13~16주차)

#### 13주차: 현장 실측 및 데이터 캘리브레이션
* **목표**: 실측 데이터와 예측 알고리즘 간 오차 보정.
* **세부 작업**:
  * 테스트베드 공원 현장 방문 및 조도/표면 온도 측정계를 활용한 모델 검증.
  * 건물 외 가로수(수목) 차폐로 인해 발생하는 그늘 오차를 보정하기 위해 공원 내 식생 수관율(Canopy Cover) 상수값 튜닝.

#### 14주차: 유저 크라우드소싱 제보 모듈 구현
* **목표**: 결측 데이터 및 현장 변수를 유저 참여로 보정하는 기능 추가.
* **세부 작업**:
  * 원터치 제보 팝업: "여기 그늘이 좋아요(가로수)", "공사/자갈길 주의", "음수대 위치".
  * 제보 누적 시 해당 링크 가중치 동적 재반영 파이프라인 연계.

#### 15주차: 폐쇄 베타 테스트 (CBT)
* **목표**: 견주 50명 대상 2주간 필드 사용성 테스트.
* **세부 작업**:
  * 산책 만족도, 경로 정확도, 배터리 소모율 모니터링.
  * 크래시 로그 수집(Sentry) 및 긴급 버그 픽스.

#### 16주차: 최종 안정화 및 스토어 런칭
* **목표**: 구글 플레이스토어 / 애플 앱스토어 정식 배포.
* **세부 작업**:
  * 스토어 등록 정보 및 스크린샷 에셋 제작.
  * 정식 서비스 버전 빌드 및 심사 제출.
