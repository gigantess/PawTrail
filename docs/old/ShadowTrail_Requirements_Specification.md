# [요구사항 정의서] ShadowTrail (섀도우트레일)

## 1. 개요 (Overview)
* **프로젝트명**: ShadowTrail (섀도우트레일)
* **프로젝트 정의**: 건물 3D 및 태양 고도/방위각 기반 시간대별 그늘 예측과 노면 재질 데이터를 기반으로, **AI Agent**, **Vision 멀티모달**, **Long-term Memory**, **노코드 자동화(n8n)**를 결합하여 반려견 맞춤형 안심 순환 산책로를 생성·추천하고 실시간 안전을 관리하는 AI Native 서비스.
* **프로젝트 목적**:
  1. 여름철 지면열 화상 및 열사병으로부터 반려견을 보호하는 그늘 중심 산책로 제공
  2. 슬개골 탈구 및 관절 질환 반려견을 위한 쿠션 노면(흙·잔디) 최적 경로 안내
  3. 주차장 거점(Park & Walk)과 연계된 자연스러운 회귀형(Loop) 동선 설계
  4. 생성형 AI 에이전트와 비전 기술, 자동화 워크플로우를 결합한 실전 AI 서비스 구현 및 배포 검증
* **대상 사용자**:
  - 도심지 및 근교에서 반려견을 산책시키는 견주
  - 관절 질환, 노령견 등 특수 보행 관리가 필요한 견주
  - 원정 산책을 위해 차량 주차 공간 연계가 필수적인 견주
  - (CBT 테스터: 최소 5인 이상의 실제 견주)

## 4. AI 활용 명세서 (AI Component Specification)

### 4.1 Walk Planning AI Agent
* **모델 및 프레임워크**: LangChain / LangGraph + GPT-4o / Claude 3.5 Sonnet / Gemini 1.5 Pro
* **에이전트 구조**: ReAct 패턴 기반 다중 도구 제어 에이전트
* **도구 명세 (Tool Definitions)**:
  1. `get_dog_health_profile(user_id)`: Long-term Memory에서 견종, 체중, 슬개골/관절 질환 단계, 이전 산책 피로도 조회
  2. `search_nearby_parking(lat, lon, radius)`: 반경 내 공영/민영 주차장 위치 및 가용 정보 검색
  3. `calculate_shadow_loop_route(origin_lat, origin_lon, target_distance, time, surface_pref)`: 그늘/노면 가중치 기반 루프 경로 연산
  4. `analyze_surface_image(image_url)`: 현장 사진의 노면 재질 및 발바닥 위험도 진단
* **시스템 프롬프트 지침**:
  - 견종 및 질환 정보를 최우선 제약으로 설정한다. (예: 슬개골 탈구 의심/확진 견종은 아스팔트 및 경사로를 배제하고 흙길/평지 비중을 70% 이상으로 강제)
  - 사용자가 시간만 제시한 경우(예: "30분 산책"), 견종별 표준 보행 속도를 환산하여 목표 거리를 자율 결정한다.

### 4.2 Multimodal Surface Inspector
* **모델**: Gemini 1.5 Flash / GPT-4o Vision
* **입력 형식**: Base64 인코딩 이미지 또는 이미지 URL (JPEG, PNG)
* **출력 스키마 (Structured JSON Output)**:
  ```json
  {
    "primary_surface": "asphalt | dirt | grass | paved | gravel",
    "surface_temperature_risk": "HIGH | MEDIUM | LOW",
    "hazard_detected": true,
    "hazard_types": ["glass", "construction_debris", "sharp_stones"],
    "safety_score": 35,
    "ai_comment": "직사광선에 가열된 아스팔트와 미세 자갈이 혼재되어 소형견 발바닥 화상 및 상처 위험이 높습니다."
  }
  ```
* **가중치 반영 로직**: `safety_score` < 50인 경우 해당 도로 링크의 보행 비용을 5배 할증하여 즉각 우회 유도.

### 4.3 Long-term Memory Architecture
* **저장 매체**: Supabase (PostgreSQL) + pgvector (선택 시 유사 피드백 검색)
* **저장 데이터셋**:
  - `User/Dog Entity`: 견종, 연령, 체중, 관절 질환 여부, 선호 산책 시간대
  - `Walk History Entity`: 산책 일시, 경로 GeoJSON, 실주행 거리/시간, 소모 칼로리
  - `Feedback Entity`: 사용자 평가(1~5점), 정성 피드백 텍스트("그늘은 좋았는데 계단이 많았어요")
* **맥락 주입 방식**: AI Agent 호출 시 최근 5회 산책 요약 및 피드백 요약본을 동적 시스템 메시지로 자동 로드.

### 4.4 Automation Pipeline (n8n Workflow)
* **트리거**: 매일 오전 10:00 Cron Trigger
* **데이터 수집**: 기상청 단기예보 API (기온, 습도, 일사량) 호출
* **연산 로직**: 간이 지면열 수지 모형을 적용해 직사광선 하 아스팔트 표면 온도 추정
* **동작**: 지면 온도가 35℃ 이하로 하강하는 최적 산책 시작 예상 시간(골든타임)을 산출하고, 사용자 웹 푸시 / 메신저 웹훅으로 알림 발송.

## 5. 시스템 아키텍처 및 데이터 흐름

```
[ 클라이언트 (Next.js / React Native Web) ]
   │  1. 자연어 발화 ("말티즈 3살, 흙길 위주 20분") & 노면 사진
   ▼
[ Backend Gateway (FastAPI) ]
   │  2. 세션 인증 및 에이전트 파이프라인 트리거
   ▼
[ Walk Planning AI Agent (LangGraph) ]
   ├──► [ Long-term Memory (Supabase) ]: 견공 건강/피드백 조회
   ├──► [ Vision Inspector ]: 노면 사진 위험도 판별 (Gemini 1.5)
   ├──► [ Spatial Routing Engine ]: PostGIS + SunCalc 그늘/노면 가중 A* 연산
   └──► [ Public Parking API ]: 인근 주차장 실시간 정보 조회
   │  3. 최적 순환 코스 및 추천 사유 종합
   ▼
[ 클라이언트 지도 시각화 ]
   │  - 노면별 색상 구분 Polyline 렌더링
   │  - 그늘 비율, 쿠션 노면 비율, 주의 구간 인포그래픽 표출
   │  4. 산책 완료 후 사용자 피드백 제출
   ▼
[ Feedback Collection Pipeline ] ──► [ Long-term Memory 축적 ]
```
