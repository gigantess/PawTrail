# [프로젝트 기획서] 반려견 맞춤형 스마트 그늘·노면 안심 산책 에이전트 (ShadowTrail)

## 1. 프로젝트 개요
* **프로젝트명**: ShadowTrail (섀도우트레일)
* **부제**: AI Native 반려견 맞춤형 스마트 그늘·노면 안심 산책 솔루션
* **정의**: 건물 3D 데이터와 태양 궤적 시뮬레이션을 결합한 시간대별 그늘 예측 정보, 노면 재질(흙·잔디·아스팔트 등) 공간정보에 **AI Agent**, **비전 멀티모달(노면 진단)**, **Long-term Memory(견공 건강 및 산책 이력)**, **노코드 자동화(n8n 알림 파이프라인)**를 융합하여 반려견에게 가장 안전하고 쾌적한 순환형 산책로를 생성·안내하는 지능형 모바일/웹 서비스.
* **핵심 타깃**:
  * 여름철 낮/오후 시간대 아스팔트 지면열 화상 및 열사병을 우려하는 견주
  * 관절 질환(슬개골 탈구, 고관절 이형성증 등) 및 노령견 케어로 흙길·잔디길 산책이 필수적인 견주
  * 자차를 이용해 근교 공원이나 산책로를 찾는 원정 산책족 (P&R: Park & Walk 연계)
* **실사용자 테스트 목표**: 반려견 견주 최소 5인 이상 대상 필드 테스트 및 피드백 수집·개선 반영

## 2. 문제 정의 및 AI 기반 해결 방식

| 문제점 (Pain Points) | AI를 활용한 해결 방식 | 적용 기술 (필수 요건 충족) |
|---|---|---|
| **실시간 노면 위험 불확실성**<br>(공사 구간, 파쇄석, 낮 시간대 가열 아스팔트) | 견주가 현장 노면 사진을 촬영해 업로드하면 Vision 멀티모달 모델이 노면 재질과 발바닥 위험도를 즉각 판독하고 라우팅 가중치에 동적 반영 | **멀티모달 AI (Vision)** |
| **반려견별 신체 조건 미반영**<br>(견종, 체중, 관절 병력, 체력 편차) | 단순 고정 알고리즘이 아닌, 견종 특성·관절 질환 이력·과거 산책 누적 피로도 맥락을 기억해 맞춤형 코스 강도를 적응형으로 제안 | **Long-term Memory** |
| **복합 조건 산책 코스 탐색의 번거로움** | "3살 말티즈, 슬개골 2기인데 주차 편하고 흙길 위주 20분 순환 코스 추천해줘"와 같은 자연어 요청을 해석해 내부 GIS/API 도구를 자율 순차 호출 | **AI Agent (ReAct Framework)** |
| **적정 산책 타이밍 파악 부재** | 기상청 지면온도/일사량 API와 연동하여 안전 지면 온도 도달 시각을 예측하고 사용자에게 자동 알림 전송 | **자동화 워크플로우 (n8n)** |

## 3. 핵심 AI 아키텍처 및 필수 기술 요소 명세

### 3.1 시스템 아키텍처 다이어그램
```
                        [ 사용자 (자연어 / 현장 사진 입력) ]
                                       │
                                       ▼
                       ┌──────────────────────────────┐
                       │    Walk Planning AI Agent    │ ◄───► [ Long-term Memory ]
                       │   (LangChain / LangGraph)    │       (반려견 건강, 과거 이력)
                       └──────────────┬───────────────┘
                                      │ 도구 호출 (Tool Calling)
           ┌──────────────────────────┼──────────────────────────┐
           ▼                          ▼                          ▼
    [ Tool 1: GIS 엔진 ]     [ Tool 2: Multimodal ]    [ Tool 3: 외부 API ]
    - 그늘 예측 (SunCalc)    - 노면 상태 사진 분석     - 전국 공영주차장 연동
    - PostGIS 루프 라우팅     - 발바닥 위험도 채점      - 기상청 단기 예보 / 지면열
           │                          │                          │
           └──────────────────────────┴──────────────────────────┘
                                      │
                                      ▼
                      [ n8n 알림 자동화 파이프라인 ]
                      (자외선/온도 모니터링 → 최적 산책 타이밍 푸시 발송)
```

### 3.2 필수 기술 요소 상세 명세 (미션 요구사항: 2개 이상 충족)
1. **AI Agent (Walk Planner Agent)**:
   - ReAct(Reasoning + Acting) 프레임워크를 기반으로 사용자의 자연어 목표를 분해.
   - `search_parking`, `calculate_shade_route`, `check_surface_safety` 도구를 자율 선택 및 실행하여 최적의 산책 플랜을 조합.
2. **멀티모달 AI (Surface Safety Inspector)**:
   - 비전 모델(Gemini 1.5 Flash 등)을 활용해 현장 노면 이미지의 재질(흙, 잔디, 아스팔트, 자갈, 보도블록) 및 이물질 위험도를 0~100 스케일로 채점하고 JSON 형태로 구조화하여 반환.
3. **Long-term Memory (Canine Context Memory)**:
   - 사용자별 반려견 프로필, 관절 병력, 이전 산책 코스에 대한 피드백(예: "지난번 코스는 언덕이 많아 힘들어함")을 영속 저장하여 차기 코스 생성 시 프롬프트 맥락으로 주입.
4. **자동화 워크플로우 (n8n Automation Pipeline)**:
   - 매일 지정 시간 기상 데이터 및 지면 온도 예측치를 배치 수집하고, 안전 기준 도달 시각에 맞춰 사용자 맞춤형 산책 리마인더 메시지를 자동 발송.

## 4. 서비스 핵심 기능 명세

| 기능 구분 | 주요 기능 | 세부 설명 | 담당 컴포넌트 |
|---|---|---|---|
| **코어 에이전트** | 대화형 산책로 생성 | 사용자 발화 기반 목표 시간, 거리, 반려견 컨디션을 고려한 맞춤형 순환 산책로 도출 | Walk Planning Agent |
| **환경 분석** | 시간대별 그늘 시뮬레이션 | 태양 고도/방위각(SunCalc) 및 건물 형상 데이터를 활용한 실시간 그늘 가중치 연산 | GIS Core Module |
| **노면 안전** | 비전 노면 판독 | 업로드된 사진을 분석하여 고온 아스팔트, 파쇄석 등 위험 구간 판별 및 우회 가중치 부여 | Multimodal Vision AI |
| **맥락 유지** | 견공 맞춤형 메모리 | 반려견의 생애주기, 질환, 누적 피로도를 축적하여 회차별 개인화 추천 정밀도 향상 | Long-term Memory DB |
| **거점 연계** | 주차장 P&R 코스 안내 | 인근 공영/민영 주차장과 연계하여 차량 주차 후 바로 출발 가능한 회귀 동선 설계 | Public Data API |
| **알림 자동화** | 산책 골든타임 리마인더 | 지면 온도가 35℃ 이하로 내려가는 쾌적 시간대를 예측하여 푸시 알림 전송 | n8n Workflow |
| **사용자 참여** | 크라우드소싱 현장 제보 | 견주들의 가로수 그늘 제보, 공사 구간 제보를 접수하여 실시간 지도 메타데이터 갱신 | User Feedback Feed |

## 5. 비기능 요구사항 및 제약사항

* **성능 및 응답성 (NFR-01)**: AI Agent 복합 도구 호출 및 경로 제안 완료 시간은 스트리밍 응답 포함 6초 이내 유지.
* **배포 및 접근성 (NFR-02)**: 외부 테스터가 별도 복잡한 설치 없이 브라우저/모바일 웹으로 접근할 수 있도록 클라우드(Vercel, Render 등) 배포 환경 구축.
* **AI 윤리 및 투명성 (NFR-03)**:
  * 생성된 산책 경로는 시뮬레이션 결과임을 UI에 명시 ("AI 시뮬레이션 경로이므로 현장 안전에 유의하세요").
  * 사용자 위치 및 반려견 정보 수집 시 필수 개인정보 수집 동의 절차 준수.
* **버전 관리 및 협업 (NFR-04)**: GitHub를 기반으로 모든 소스 코드 및 기술 문서를 버전 관리하며, PR 리뷰 및 이슈 트래커 활용.

## 6. 비즈니스 모델 및 확장 가능성

* **로컬 펫 프렌들리 상권 제휴**: 산책로 경유지 및 도착지 주변 반려견 동반 카페, 식당, 펫용품점 위치 기반 제휴 쿠폰 연동.
* **지자체 협업 스마트 시티 솔루션**: 견주 통행 패턴 및 그늘 결측 구간 데이터를 분석하여 반려견 보행 인프라(가로수 식재, 배변봉투함 설치) 최적 입지 리포트 제공.
* **프리미엄 구독 (ShadowTrail Plus)**: 정밀 반려견 칼로리/관절 부담도 리포트, 오프라인 안심 지도 다운로드, 1:1 AI 건강 산책 코칭 제공.
