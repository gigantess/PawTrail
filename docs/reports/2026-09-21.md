## 2. 모듈별 세부 구현 및 변경사항 (Implementation Details)

### 🧠 AI Agent & Intelligence (Member A, B)
* **AI Agent (Member A / 52 h)**:
  - **무상태(Stateless) 프롬프트 오케스트레이션 수립**: 서버 DB에 사용자의 민감 개인정보나 과거 히스토리를 쌓지 않고, 산책 요청 시 클라이언트가 동봉한 일회성 페이로드(`client_dog_context`, `client_recent_feedback`)를 통해 의도를 분석하고 제약조건을 동적 바인딩하도록 설계.
  - **대화형 자연어 산책 요청 파싱 (US-A1 / TASK-A1-1~4)**: `TargetDuration`, `AvoidStairs`, `SlopePreference`, `ShadePriority` 4대 엔티티 추출률 85% 이상 검증 스키마 및 예외 시 안전 기본값(완만 경사, 계단 회피, 20분) 폴백 아키텍처 정립.
  - **로컬 피드백 기반 동적 가중치 보정 (US-E3 / TASK-E3-1~3)**: 클라이언트의 최근 피드백 요약(예: "경사 불만족 1회") 수신 시 허용 최대 경사도를 1~2% 하향 조정하는 무상태 피드백 반영 체계 설계.
* **Vision AI (Member B / 28 h)**:
  - **실시간 산책 촬영 배제 및 현장/안내판 2대 축 안착 (US-D1 / TASK-D1-1~4)**: 리드줄을 쥔 상태에서 바닥을 계속 촬영하는 위험을 원천 차단하고, 산책 전 **공원 종합안내판 판독(`ParkBoardInspector`)** 및 **현장 높은 턱/계단/공사 장애물 사진 판독(`HazardInspector`)**으로 역할을 명확화.
  - **Pydantic V2 기반 Structured JSON 출력 표준화**: 비전 분석 응답에 위험도(`warning`, `danger`), 권장 조치, 반려견 출입 금지 구역 파싱 결과를 규격화하여 반환하도록 설계.
  - **동적 위험 우회 연계 (US-D2 / TASK-D2-1~4)**: 위험 지점 좌표 감지 시 해당 링크에 10배 비용 페널티 또는 차단 가중치를 부여하고 3초 이내 대안 우회로를 도출하는 백엔드 라우팅 연계 인터페이스 정의.

### 🗺️ Backend & Spatial Routing (Member C / 126 h)
* **FastAPI & GIS Routing**:
  - **가용 데이터 중심 다요소 라우팅 파이프라인 (Epic B / TASK-B1~B4)**:
    - **계단 우선 회피 (US-B1)**: OSM `highway=steps` 링크를 하드 제약으로 배제하고 `has_stairs: false` 메타데이터 및 신뢰도 반환.
    - **DEM 완만 경사도 제어 (US-B2)**: 수치표고모델(DEM) 고도 래스터를 도로망 링크에 매핑하여 종단 경사도(`slope_percent`) 산출, 급경사(>8%) 페널티 가중치 부여 및 최대/평균 경사도 연산.
    - **SunCalc 태양/건물 차폐 그늘 평가 (US-B3)**: 천문학적 태양 위치(고도각/방위각)와 건물 형상 레이어를 결합하여 11~15시 피크 시간대에 그늘 비율이 높은 링크에 비용 할인($W_{\text{shade}} = 0.6$) 적용.
    - **Routing API Adapter & Candidate Scorer (US-B4)**: 검증된 전문 라우터(ORS/OSRM)로 2~3개 후보 순환 경로를 수집하고, Candidate Route Scorer가 4대 요소(계단, 경사, 그늘, 시간 오차)를 종합 채점(100점 만점)하여 최적 코스 선정.
  - **체급별 표준 보행 속도 상수 정합화 (US-A3 / TASK-A3-1~3)**:
    - 소형견(2.8 km/h), 중형견(3.6 km/h), 대형견(4.2 km/h), 노령견/관절안심케어(2.2 km/h)로 전 문서 수치 일치.
    - 10~90분 슬라이더 입력 시 목표 거리 환산 및 생성 코스 시간 오차 $\pm 15\%$ 수렴 알고리즘 확립.
  - **출발 거점 연계 P&R 공영주차장 코스 탐색 (US-G1 / TASK-G1-1~3)**: 공공데이터포털 전국 공영주차장 API를 연계하여 반경 1.5km 이내 주차장 출입구를 출발/도착 웨이포인트로 스냅하는 순환 라우팅 설계.

### 📱 Frontend & Mobile Native UX (Member D / 127 h)
* **React Native (Expo SDK 51+) 전환 및 핸즈프리 음성 안내**:
  - **모바일 웹의 한계 극복**: 화면 꺼짐 시 OS에 의해 GPS/TTS가 백그라운드 스로틀링되는 모바일 웹(PWA)을 전면 폐기하고, 하드웨어 백그라운드 제어가 가능한 React Native Expo 스택으로 전환.
  - **시선 해방(Eyes-Free) 핸즈프리 음성 내비게이션 (US-C2 / TASK-C2-1~4)**:
    - Android Foreground Service + `expo-location`을 통한 화면 잠금(주머니 보관) 상태의 무중단 백그라운드 GPS 트래킹.
    - OSRM 턴바이턴 스텝과 경로 속성을 결합하여 회전 30m 전 `expo-speech` TTS로 *"50m 앞 완만한 길입니다. 우회전하세요"* 사전 브리핑 송출 및 40m 이탈 감지 음성 안내.
  - **React Native Maps 구간별 색상 분기 Polyline (US-C1 / TASK-C1-1~4)**:
    - 완만/그늘길: 초록(`#10B981`), 일반 보도: 파랑(`#3B82F6`), 탄성포장: 주황(`#F97316`), 높은 턱/주의: 빨강(`#EF4444`)으로 시각적 신뢰도 극대화.
  - **프라이버시 로컬 스토리지 매니저 (US-A2, US-E1 / TASK-A2-1~4, E1-1~4)**:
    - `@PawTrail:dog_profile`, `@PawTrail:walk_history` 키 기반 `AsyncStorage` 로컬 영속화 및 기기 변경 대비 JSON 내보내기/가져오기(Export/Import) 모듈 설계.
  - **긍정적 웰니스 카피라이팅 가드레일**: 앱 UI 전역에서 '슬개골 탈구' 등 임상 질병 단어를 100% 제거하고 "관절 안심 케어", "폭신한 길 위주" 등 정서적 안정감을 주는 카피로 전면 치환.

  - **무선 무점검 OTA 배포 파이프라인 (US-H1 / TASK-H1-1~4)**:
    - EAS Build 기반 테스터용 Android APK 1회 패키징 배포 체계 수립.
    - 코드 수정 및 UI 핫픽스는 GitHub Actions 연동 `eas update` (`expo-updates`) 무선 OTA로 실시간 배포하여 테스터 앱 재설치 피로 원천 해결.
  - **Supabase Cloud 간편 인증 및 커뮤니티 200m 공간 마스킹 (US-G2 / TASK-G2-1~4)**:
    - 소셜 OAuth 의존성을 제거하고 `Supabase Auth` 기반의 간편 이메일/비밀번호 가입(Auto-confirm) 체계 도입.

  - **기상청 단기예보 n8n 연동 지면열 위험 지수 (US-F1 / TASK-F1-1~4)**:
